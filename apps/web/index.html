MDX → MIDI

X68000 の MDX (MXDRV) を Standard MIDI File に変換します。PDX を一緒に読み込むと、ADPCM パートを鳴らす SoundFont (.sf2) も作ります。ファイルはブラウザ内で処理され、サーバには送信されません。

変換オプション

使い方メモ

  • MIDI は FM 8ch を MIDI ch1–8 に、ADPCM (PCM8 時は最大 8ch) を ch10 と ch9・11–16 に割り当てます。
  • SF2 モードでは、ch10 は SF2 のドラムキット (bank 128)、それ以外の ADPCM ch は bank 127 / program 0 を使います。GM 音源用の SoundFont と一緒に読み込んで再生してください。
  • FM 音色は GM 音色に近似して割り当てます(音色の完全再現はできません)。
  • VOPM モード: MDX の FM 音色を VOPM 用の .OPM バンクとして書き出し、MIDI のプログラムチェンジをバンク内の番号(原則 MDX の @番号そのまま)にします。DAW で VOPM を 8 つ立ち上げ、それぞれに .OPM を読み込んで MIDI ch1〜8 を割り当ててください。音量は MXDRV と同じくキャリアの TL に加算した音色として .OPM に入れ、プログラムチェンジで切り替えます(VOPM の CC7 やベロシティには依存しません)。音色×音量の組が 128 を超える曲は FM チャンネルごとの .OPM を出力します。
  • OPM68 モード: 同梱の YM2151 プラグイン OPM68 (VST3/CLAP) 用です。.opm をプラグインに読み込み、各 FM トラックに 1 つずつ割り当てます。音色と音量はノートのベロシティ (1〜127) で選ぶので、DAW がプログラムチェンジや MIDI チャンネルを無視しても正しく鳴ります。
  • LZX 圧縮された MDX には未対応です。
